● Proposal: Professional Auction Transfer Validation System

  Overview

  After confirming receipt, buyers must submit transfer evidence for platform validation before escrow release. This
  ensures legitimate transactions and protects both parties.

  ---
  📋 Phase 1: Evidence Collection

  Transfer Evidence Requirements (Based on eBay Motors, Bring a Trailer best practices)

  Document Uploads (Required)

  1. Deed of Sale
    - Signed by both buyer and seller
    - Must include: Sale price, date, vehicle details, both signatures
    - File types: PDF, JPG, PNG
  2. Transfer of Registration (CR/OR)
    - Official LTO document showing ownership transfer
    - Must be signed by seller
    - Clear photo/scan required
  3. Official Receipt (OR)
    - Proof of payment for transfer fees
    - LTO-issued document
    - Date must be within 7 days of receipt confirmation

  Vehicle Verification (Required)

  4. Vehicle at Buyer's Location
    - Photo of car at buyer's address
    - Must show recognizable location marker
    - Metadata timestamp preserved
  5. Odometer Reading
    - Clear photo of current mileage
    - Must match or be close to listing mileage (±50km tolerance)
    - Timestamp visible
  6. VIN Plate Verification
    - Photo of chassis number plate
    - Must match auction listing VIN
    - Clear, readable image

  Condition Documentation (Required)

  7. 4-Angle Vehicle Photos
    - Front, rear, driver side, passenger side
    - Taken at buyer's location
    - Same day as receipt confirmation
  8. Damage/Issue Photos (If applicable)
    - Photos of any damage not disclosed in listing
    - Close-ups of problem areas
    - Required if condition differs from listing

  Signatures (Required)

  9. Delivery Receipt
    - Pre-filled form with vehicle details
    - Both parties sign digitally or upload signed copy
    - Includes: Delivery date, condition notes, acceptance

  TransferEvidence Model

  @freezed
  abstract class TransferEvidence with _$TransferEvidence {
    const factory TransferEvidence({
      required String id,
      required String transactionId,
      required String buyerId,
      required DateTime submittedAt,

      // Documents
      String? deedOfSaleUrl,
      String? crOrTransferUrl,
      String? officialReceiptUrl,

      // Vehicle photos
      required List<String> vehiclePhotoUrls,
      String? odometerPhotoUrl,
      String? vinPhotoUrl,
      int? odometerReading,

      // Condition photos
      required List<String> conditionPhotoUrls,
      List<String>? damagePhotoUrls,

      // Delivery receipt
      String? deliveryReceiptUrl,
      String? buyerNotes,
      bool buyerSignature,

      // Validation
      required ValidationStatus status,
      DateTime? validatedAt,
      String? validatedBy,
      String? rejectionReason,

    }) = _TransferEvidence;
  }

  enum ValidationStatus {
    pending,      // Just submitted
    underReview,  // Being reviewed
    approved,     // Validated successfully
    rejected,     // Needs correction
    moreInfoNeeded, // Additional docs required
  }

  🔄 Updated Escrow Flow

  Complete Flow:

  1. Auction Won
     ↓
  2. Payment Submitted → EscrowStatus.pending
     ↓
  3. Payment Processed → EscrowStatus.held
     ↓
  4. Seller Ships Vehicle
     ↓
  5. Buyer Clicks "Confirm Receipt"
     ↓
  6. Submit Transfer Evidence Form (7 steps)
     ↓
  7. Evidence Submitted → EscrowStatus.validating
     ↓
  8. Mock Validation (5-10 seconds, shows 1-3 days)
     ↓
  9. Validation Approved → EscrowStatus.released
     ↓
  10. Payment Released to Seller

  Auto-Release Rules:

  - If validation pending > 3 business days → Auto-approve
  - If buyer doesn't submit evidence within 7 days → Prompt
  - If buyer doesn't submit evidence within 14 days → Auto-approve without evidence (risky for buyer)
